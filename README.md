# english-850

用 850 个英文单词，把看到的事说出来。

> 状态：**已上线** → https://lichlong.github.io/english-850/
> 手机浏览器打开，可「添加到主屏幕」当应用用。

## 它做什么

每天一个单元：短句 → 长句 → 短文，点任意词出中文，读完自动记录。
「课外拓展」和「课外练习」两块从**第一天**就有：

- **原文**：地道的全量英文（不限词）
- **简说**：同一段意思，只用 850 词重新说一遍
- **课外练习**：给中文句，自己先在心里说，再点参考答案对照

前 5 天两块合在一屏、各给一条（预览）；第 6 天起各占一屏、正式放量。
练习句按课时解锁：读到哪一课，就只出那几课里出现过的词。学完 850 后脱离课时，全池随机。

## 要多久（实话）

| 目标 | 时间 |
|---|---|
| 850 词全部至少见过一次 | **约 39 天**（每天一个单元，5 分钟） |
| 300 个词达到巩固（接触 ≥15 次） | **约 90 天** |
| 全部 850 词都巩固 | 约 8–11 个月（理论上限） |

每天 3 分钟也能学，但单元要拆成两天，一轮变 57 天。
断更不清零、不补课、不惩罚：回来接着上次的地方走。

## 词汇口径

严格按 Ogden《Basic English》850 词原表：表里有的不能漏，表里没有的不能加。
两类例外都单独立表、单独统计：

- `WORD_ALLOWED` 539 条：原文规则明文允许的（代词、数字、日历、单位、`-ly/-er/-est` 派生）
- `WORD_DEVIATION` 50 条：确认放行的表外词（与原版有细微区别，清单见 `tools/basic-850-deviation.txt`）

## 技术

纯静态网页 + PWA，无后端、无账号、无追踪。
加到主屏后可离线打开（`sw.js`：网络优先，断网回缓存）。
阅读记录只存在浏览器本地，不进仓库。

```
data/      内容（词表、单元、课外）
js/        逻辑（一功能一文件，均 < 300 行）
tools/     内容生产与体检脚本
SPEC.md    合同：所有口径以此为准
HANDOFF.md 交接单：接手先读这个
```

## 内容体检

```bash
node tools/measure.js     # 单元/简说/练习池超纲必须 0，练习池档位长度必须合规
node tools/coverage.js    # 词覆盖缺口、下一批该挑哪 22 个新词
node tools/test-draw.js   # 练习池抽取规则自测（不开浏览器）
```
